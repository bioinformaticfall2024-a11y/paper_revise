# Paper revision reproducibility repository

This repository organizes code and analysis used to address reviewer comments for the manuscript revision.

Each reviewer comment that requires code, quantitative verification, or reproducible analysis is stored in its own numbered folder. The first added analysis is:

- `Reviewer_3/Comment_08_Ligand_SMARTS_Coverage/` — dataset-wide audit of the 20 ligand-side FGgraphDTA SMARTS patterns and reproduction of the six-inhibitor calculation discussed by the reviewer.
