1. VERIFIED FACT
=====================================================================
The primary DGraphDTA paper (Jiang et al., RSC Advances, 2020; DOI: 10.1039/D0RA02297G) reports the following KIBA result in Table 8:

DGraphDTA (GCN & GCN):
CI = 0.904
MSE = 0.126
Pearson = 0.903

The current manuscript instead lists DGraphDTA as CI = 0.891, MSE = 0.147, Pearson = 0.903 and labels the row "reproduced". If this row is intended to represent the published DGraphDTA result, it is incorrect.

Using the published MSE of 0.126, the current proposed-model KIBA MSE values are:
FGgraphDTA: 0.145, which is 15.08% higher than 0.126.
PVgraphDTA: 0.130, which is 3.17% higher than 0.126.

These percentages are descriptive cross-study differences only. They must NOT be presented as controlled performance effects because the evaluation protocols are different.

=====================================================================
2. RESPONSE TO REVIEWER — COPY-PASTE VERSION
=====================================================================
We thank the reviewer for identifying this inconsistency. We rechecked the primary DGraphDTA publication and confirm that the published KIBA results for DGraphDTA are CI = 0.904, MSE = 0.126, and Pearson correlation = 0.903. The values previously shown in our KIBA table (CI = 0.891, MSE = 0.147, Pearson = 0.903) therefore should not have been presented as the published DGraphDTA result.

We have corrected the DGraphDTA row in the KIBA comparison table to the values reported in the primary source and relabeled it as a literature-reported result rather than a reproduced result. Consequently, we removed the statement that PVgraphDTA reduces KIBA MSE by approximately 11.4% relative to DGraphDTA, because that statement was calculated from the incorrect MSE value of 0.147. We also removed statements describing PVgraphDTA as outperforming DGraphDTA or as achieving the strongest overall KIBA performance.

With the corrected literature values, the published DGraphDTA result is numerically better than FGgraphDTA and PVgraphDTA on KIBA for MSE, CI, and Pearson correlation. We have therefore rewritten the KIBA Results, Discussion, Abstract, and Conclusion to report the proposed-model results in a dataset- and metric-specific manner and to avoid unsupported superiority claims.

We additionally clarify that the DGraphDTA values are taken from the original publication, whereas our proposed models were evaluated under the experimental protocol described in this manuscript. Because these protocols are not identical, the literature values are now presented as descriptive reference values rather than as matched head-to-head reruns, and we do not calculate percentage improvements from this cross-study comparison.
