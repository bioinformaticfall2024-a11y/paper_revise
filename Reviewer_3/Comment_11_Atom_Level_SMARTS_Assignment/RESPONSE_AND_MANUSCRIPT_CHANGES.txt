1. RESPONSE TO REVIEWER

We thank the reviewer for pointing out that our description of atom-level SMARTS assignment was insufficient for reproducibility. We have revised the FGgraphDTA methodology to specify how a multi-atom substructure match is projected onto individual ligand-atom features, how repeated matches are treated, and how overlaps between functional-group patterns are handled.

For each of the twenty predefined SMARTS patterns, RDKit identifies the substructure matches in the ligand molecular graph. Every atom participating in each returned match is assigned a value of 1 in the corresponding functional-group dimension; the indicator is not restricted to a representative atom. The assignment is binary, so multiple occurrences of the same pattern involving an atom do not increase its bit beyond 1. The patterns are evaluated independently. Consequently, when an atom participates in matches of different functional-group patterns, multiple bits can be active simultaneously in its twenty-dimensional functional-group vector.

For example, in a molecule containing an ester, all atoms returned by the ester SMARTS match receive the ester indicator. If one of these atoms also participates in an ether SMARTS match, the original atom-level encoding may assign both the ester and ether indicators. The model uses this multi-hot functional-group annotation alongside the original atom descriptors and molecular graph connectivity, rather than treating the functional-group labels as mutually exclusive classes.

We have also clarified the scope of the refinement step discussed previously using the phenol–alcohol example. The precedence rules described for the molecule-level functional-group summary are separate from the default atom-level encoding used as ligand-model input; they do not automatically remove overlapping bits from the atom-level feature matrix. We have corrected the Methods wording so that the refinement example is not presented as a general atom-level overlap-resolution algorithm.

The twenty-dimensional functional-group vector for each ligand atom is concatenated with its original seventy-eight-dimensional atom descriptor vector, yielding the ninety-eight-dimensional ligand-atom features used in FGgraphDTA. These clarifications specify the complete substructure-to-atom projection rule without changing the proposed architecture.
