METHODS TEXT
For each SMARTS query, all RDKit substructure matches were enumerated. Every atom index participating in a match was assigned a value of 1 in the corresponding functional-group dimension. Because dimensions were evaluated independently, an atom could carry more than one functional-group bit when SMARTS patterns overlapped; no representative atom was selected.

Do not retain the old claim that phenol/alcohol cleanup was applied to the historical per-atom training features unless the result-producing code proves it.
