RESPONSE TO REVIEWER
We thank the reviewer for prompting an exact recount. The standard torchvision ResNet-101 contains 44,549,160 parameters with its 1000-class classifier. In our feature extractor, the final 2048x1000 classifier (2,049,000 parameters including bias) is replaced by an identity layer, leaving 42,500,160 backbone parameters; therefore the earlier ~42.5M value refers specifically to the headless backbone. We agree, however, that the complexity table was internally inconsistent and that calling the ~19.76M subtotal the full pipeline was misleading because it omitted the ResNet backbone.

We also re-counted the graph models. The 78/54 base graph architecture has 1,693,525 parameters, whereas FGgraphDTA with 98/74 inputs has 1,924,525, an increase of 231,000. The previous table incorrectly listed both as ~1.925M. We have replaced the table with exact component-wise counts and explicitly state which components are included and which are trainable.
